How to buy $BUN

Four steps on Robinhood Chain. Swap only against this contract. Tickers can be copied. Addresses cannot.

  1. 01

    Add the chain

    Open an EVM wallet and add Robinhood Chain. Robinhood Wallet already includes it. Any other EVM wallet can add it by hand.

    • NetworkRobinhood Chain
    • Chain ID4663
    • GasETH
    • RPC rpc.mainnet.chain.robinhood.com

    Fund with ETH

    Bridge ETH onto Robinhood Chain. You need it both for the swap and for the network fee. Nothing on this chain is paid in another gas token.

    Open Uniswap

    Connect the wallet and switch the network to Robinhood Chain before you search for a token. The swap page below opens on that chain.

    Swap for $BUN
